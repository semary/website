## Development

The website uses HTML, CSS, and lightweight JavaScript, with deployment through Netlify.

To preview locally:

```sh
python3 -m http.server 8765
```

Open `http://localhost:8765/`. Run `python3 scripts/check_site.py` to validate local links, structured data, and profile consistency.
